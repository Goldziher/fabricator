import { Card, CardGrid } from "@astrojs/starlight/components";

```go
type Person struct {
	ID        int
	FirstName string
	LastName  string
	Email     string
}

firstName := fabricator.FieldOf[Person, string]("FirstName")
id := fabricator.FieldOf[Person, int]("ID")

factory := fabricator.New(Person{},
	fabricator.Value(firstName, "Moishe"),
	fabricator.Field(id, func(ctx fabricator.BuildContext) int {
		return ctx.Iteration + 1
	}),
)

person := factory.Build()
people := factory.Batch(10)
```

<CardGrid>
    <Card title="Typed field references" icon="approve-check">
        `FieldOf[Person, string]("FirstName")` checks at construction that the field
        exists, is exported, and accepts the value type. A typo fails immediately,
        not three assertions later.
    </Card>
    <Card title="Generated by default" icon="random">
        Unconfigured fields are filled by
        [go-faker](https://github.com/go-faker/faker). Configure only what the test
        is actually about.
    </Card>
    <Card title="Reproducible when you need it" icon="seti:clock">
        `Seed` pins generation so a test that fails on generated data fails the same
        way next run. `WithoutFaker` drops generation entirely for exact fixtures.
    </Card>
    <Card title="Factories from factories" icon="puzzle">
        `Extend` derives a variant without restating the base. Subfactories nest
        whole factories into struct, pointer, and slice fields.
    </Card>
    <Card title="Errors, not just panics" icon="warning">
        Every panicking method has an error-returning twin: `BuildE`, `BatchE`,
        `CreateE`, `CreateBatchE`.
    </Card>
    <Card title="Persistence built in" icon="seti:db">
        Give a factory a `PersistenceHandler` and `Create` builds and saves in one
        step, with a context.
    </Card>
</CardGrid>

## Install

```shell
go get github.com/Goldziher/fabricator/v2
```

Fabricator requires Go 1.26 or newer.
